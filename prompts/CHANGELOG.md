# Prompt changelog

## triage_v1 / repair_v1 — 2026-10-07
Initial versions.
- Fixed six-category set and three priorities with one-line definitions each, so labels are defensible and repeatable.
- Explicit rule for multi-issue tickets (pick the issue the customer most wants resolved).
- Ticket text is wrapped in `<ticket>` tags and declared untrusted, to reduce prompt-injection effects.
- JSON-only output with exact keys and length limits (200/300 chars, below the schema's 300/400 hard limits for headroom).
- Repair prompt receives the ticket, the invalid output and the validation error, and may re-classify if the output is unusable.

Eval results for this version: see the README results section (generated by `python evals/run_eval.py`).
