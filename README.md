# Support Ticket Triage Agent

## What it does

An automated customer support ticket triage service that takes one raw customer support ticket and returns a validated JSON triage result (`category`, `priority`, `summary`, `reason`). It is a small FastAPI service that calls Claude, validates the output against a strict schema, repairs it once if invalid, and fails with a clear HTTP error if validation fails.
